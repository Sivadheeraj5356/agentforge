# private-eval family

Long-horizon **private RL / RLVR** packs. The first world is a stalled release train across three operator sessions (triage, repair, handoff) on Simulated ops console, Simulated runbook, and Simulated handoff board.

Compare your agent on the same immutable version. This family does not publish a live named-model score.

`apps/web` never starts this world. The evaluator loads `environments/packs/private-eval-long-horizon.json`.
